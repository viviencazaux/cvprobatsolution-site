Données personnelles

Politique de confidentialité

Cette page décrit les principes de traitement des informations transmises via le formulaire de contact du site CV PRO BAT SOLUTION.

Données collectées

Le formulaire peut permettre de transmettre les informations suivantes : nom ou société, email, téléphone, type de demande, localisation du projet et message libre.

Finalité

Ces informations sont utilisées uniquement pour comprendre la demande, recontacter la personne concernée et évaluer les suites possibles à donner à la mission.

Base de fonctionnement du formulaire

Le site utilise un lien email prérempli. Les informations ne sont pas stockées dans une base de données du site. Elles sont transmises par la messagerie de l'utilisateur vers l'adresse de contact de CV PRO BAT SOLUTION.
